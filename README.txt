LEAFLET.JS + OPEN-METEO GEOCODING API: CITY LOCATION FINDER

Purpose: Search for a city and display matching geocoding results on a Leaflet map.

Run in VS Code:
1. Open this folder in VS Code.
2. Open index.html with the Live Server extension (recommended).
3. Enter Manila, Cebu, Davao, or another city name, then press Search.
4. Click map markers to show the location's name and region/country.

Teaching concepts: fetch(), async/await, response.ok, JSON, results arrays,
forEach(), dynamic markers, setView(), fitBounds(), error handling, DOM safety.

API: https://geocoding-api.open-meteo.com/v1/search
Documentation: https://open-meteo.com/en/docs/geocoding-api
Leaflet: https://leafletjs.com/

Internet is needed for Leaflet CDN, OpenStreetMap tiles, and geocoding requests.
Open-Meteo's free API is intended for non-commercial use; review their licence.
OpenStreetMap tile usage policies apply for hosted tile services.
